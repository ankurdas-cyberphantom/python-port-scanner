# 🔍 Python Port Scanner

## 📌 Overview
A fast and lightweight port scanner built using Python. It scans target systems to identify open ports and potential services.

⚠️ Disclaimer
This tool is created for educational purposes only. Do not use it on networks or systems without proper authorization.

## ⚙️ Features
- Scan single or multiple ports
- Fast scanning
- Simple and clean output

## 🚀 Usage
```bash
python port_scanner.py
Output Example -

Enter IP address: 127.0.0.1
Enter start port number: 0
Enter end port number: 100

Scan started at: 2026-04-13 09:03:27.103748
No open ports found in the given range.
Scan ended at: 2026-04-13 09:05:08.178640
Total time: 0:01:41.074892
```

Note: Output may vary depending on the target system and network configuration.
